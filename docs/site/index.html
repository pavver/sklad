See everything installed on Arch Linux. Remove what you no longer use.

Package managers only tell you what they installed themselves. Sklad puts pacman and AUR packages, Flatpak apps, Steam games, Rust toolchains, Cargo, npm and Python tools, and loose files in one list. Sort it by last launch, read what each entry is, and uninstall it with a command you see before it runs.

Install from the pacman repositorySource on GitHub

What it does

  • One catalogue of programs, console tools, libraries, fonts, drivers and metapackages, from every source.
  • Last launch from the KDE Plasma log and Steam, to find what has gone unused.
  • Unneeded dependencies (orphan packages) and packages you installed yourself, apart.
  • Safe removal: the list is checked with pacman -Rp first, and the exact command is on screen.
  • Out of a metapackage: remove one program, the rest of the metapackage stays.
  • Launch a program from its card, and copy any text you see.
  • Ukrainian and English, light and dark themes.

Safe removal

The list of packages is computed on the dependency graph by the same rules as pacman -Rs, then checked by pacman -Rp. If the lists differ, nothing happens. Important system packages and files outside your home folder need a second confirmation.

Install

Trust the signing key of the repository once:

curl -sL https://pavver.github.io/sklad/sklad.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key EB0FE0C7F0FEBBD1A40F8F93A7A3ED14D1C98D8D

Add the repository to /etc/pacman.conf:

[sklad]
Server = https://pavver.github.io/sklad/$arch

Then install it like any package; updates come with pacman -Syu:

sudo pacman -Sy sklad

Or build it from source with cargo install --git https://github.com/pavver/sklad.

Questions

How do I find unused packages on Arch Linux?

pacman -Qdtq lists orphans, but not programs you installed and stopped using. Sklad sorts everything by the last launch Plasma and Steam recorded, so the programs untouched for months come first.

How is it different from Pamac, Octopi or BleachBit?

Pamac and Octopi manage pacman packages, BleachBit cleans caches. Sklad shows what is installed across pacman, AUR, Flatpak, Steam and language package managers in one list, and removes it through the manager that installed it.

Does it need KDE Plasma?

It is tested on KDE Plasma under Wayland. The last launch of programs comes from the Plasma log, so on other desktops it is known for Steam games only; the catalogue and removal do not depend on the desktop.

Is it safe?

Sklad never removes anything without showing the command first, and pacman checks the list before it runs. It is an early version, so read the command before you confirm it.
